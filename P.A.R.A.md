# Arquitectura de Conocimiento - Metodología P.A.R.A.

Este repositorio utiliza el sistema P.A.R.A. para organizar el conocimiento, código y automatizaciones del Clon Digital.

## 📁 Estructura del Repositorio

### 1. `1_Projects/` (Proyectos Activos)
*Metas específicas con plazo o entregables definidos.*
* **Ejemplos:** Desarrollo de bots, scripts de raspado activo, integraciones de API.

### 2. `2_Areas/` (Áreas de Responsabilidad)
*Sistemas, mantenimientos y estándares continuos sin fecha de fin.*
* **Ejemplos:** Security & Blindaje (`blindar.sh`), Configuración del Entorno, Telemetría (`state.json`), Prompts base.

### 3. `3_Resources/` (Recursos y Referencias)
*Material de consulta, librerías, snipets de código y documentación útil.*
* **Ejemplos:** Guías de Bash, Cheatsheets de Git, documentación de Ollama/Llama 3, colecciones de scripts utilitarios.

### 4. `4_Archives/` (Archivos Inactivos)
*Proyectos completados, código obsoleto o respaldos que se conservan para historial.*
* **Ejemplos:** Versiones antiguas de scripts, experimentos pausados.
