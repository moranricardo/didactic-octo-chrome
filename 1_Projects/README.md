# 🚀 1_Projects (Proyectos Activos)

Esta carpeta aloja las herramientas, bots y desarrollos que se encuentran en ejecución o construcción activa.

## 📋 Estructura Sugerida para cada Proyecto:
- `1_Projects/mi-bot/`
  - `src/` -> Código fuente.
  - `config/` -> Configuración específica.
  - `README.md` -> Meta y alcance del proyecto.
